# 图片素材生成提示词

> 说明：本应用以“温暖、治愈、可爱”的养成存钱 UI 为核心，图片素材建议使用透明背景、扁平插画风，便于直接放进主界面和角色卡片。
>
> 图片格式要求：PNG，透明背景，分辨率 1080×1080，适配 Android 2x/3x，文件名使用英文小写 + 下划线，统一放到 app/src/main/res/drawable 目录。

## 6. 生成规则
- 风格统一：扁平插画、温暖色系、圆润线条、透明背景
- 适配场景：Android app 组件、首页背景、事件卡片、按钮小图标
- 导出要求：PNG，透明底，1080×1080，尽量保持主体清晰、轮廓简洁
- 文件命名范例：baby_boy_main.png、cat_scene_bg.png、vaccine_icon.png

## 7. 额外建议
如果你后续准备做动效，可以优先把以下几个素材固定：
1. 主角色形象（男婴/女婴/猫/狗）
2. 事件弹窗图标（奶粉、疫苗、玩具）
3. 养育背景图（婴儿房/宠物角/公园）
4. 空状态插画（选择角色）
5. 成就徽章

这些素材可以直接支撑 M1/M2 阶段开发。
