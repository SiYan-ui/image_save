# 「养成存钱罐」 v1.0 可落地产品方案

> **版本号**：v1.0 | **编写日期**：2025年 | **面向对象**：开发团队 | **用途**：直接落地开发指南

---

## 一、产品概述

### 1.1 产品定位

「养成存钱罐」是一款**以模拟养育为核心玩法的存钱激励APP**。用户在APP中选择养育虚拟对象（男婴/女婴/宠物猫/宠物狗），系统根据真实成长周期自动生成各类开销事件（奶粉、疫苗、猫粮、驱虫等），每个事件对应一笔建议存款金额。用户在自己的存钱工具中存入对应金额后，在APP中确认，即完成一次"存钱"行为。

**核心创新**：用游戏化的模拟养育机制，为存钱行为赋予具体的情感意义，而非冷冰冰的数字目标。

**产品定位公式**：存钱提醒器 + 开销模拟器 + 消费统计工具 = 存钱激励平台

**产品名称**：《养成存钱罐》（英文可为 Growing Piggy Bank 或 Pet Money Pot）

### 1.2 核心价值

| 价值维度 | 说明 |
|---------|------|
| **对用户** | 存钱有理由：每一笔存款对应"宝宝奶粉钱"这样有温度的故事，降低存钱心理阻力 |
| **情感驱动** | 养育虚拟对象过程中产生情感投入，转化为持续存钱的动力 |
| **成本预知** | 提前感知养孩子/养宠物的真实消费成本，为未来做财务准备 |
| **低门槛体验** | 无需真实养育即可模拟体验，适合备孕人群、租房族等 |
| **可视化反馈** | 累计金额、物品栏、角色成长都是存钱成果的直观体现 |

### 1.3 目标用户

| 用户群体 | 特征 | 核心痛点 | 使用场景 |
|---------|------|--------|---------|
| **备孕/准父母** | 22-35岁，计划要孩子 | 对育儿成本没有概念，缺乏存钱动力 | 了解养育成本，建立育儿基金 |
| **新手父母** | 有0-3岁宝宝 | 育儿开销大，难以管理 | 跟踪实际开销，规划支出 |
| **宠物主人** | 养猫/狗爱好者 | 定期支出多，易遗漏 | 记录宠物医疗/食物费用 |
| **存钱困难户** | 有存钱意愿但缺乏动力 | 传统存钱方式冷冰冰，难以坚持 | 通过游戏化方式建立习惯 |
| **学生/租房族** | 条件受限，暂时无法养宠 | 想体验养宠但现实困难 | 云养宠物，为未来存钱 |

**用户画像**：一二线城市，年龄22-35岁，女性占比略高，有可支配收入，喜欢可爱/治愈内容，愿意尝试新鲜APP。

### 1.4 产品不做什么

- ❌ **不涉及真实资金管理**：APP不接触用户资金，不支持支付、转账等操作
- ❌ **不需金融牌照**：纯记录和提醒工具，规避监管风险
- ❌ **不跟踪真实存钱**：用户手动确认存入金额，APP不验证真实行为（MVP阶段）
- ❌ **不支持社交**：v1.0阶段关闭分享功能，避免攀比心理

## 二、功能模块详设

### 2.1 养育对象管理

**支持的养育对象（v1.0）**

| 类型 | 性别/品种 | 成长阶段 | 典型开销事件 |
|------|---------|--------|-----------|
| **婴儿** | 男孩 / 女孩 | 新生儿(0-3月) → 婴儿(4-12月) → 幼儿(13-36月) | 奶粉、纸尿裤、疫苗、体检、辅食、早教 |
| **宠物猫** | 不分品种 | 幼猫(0-6月) → 成年(7-84月) | 猫粮、猫砂、疫苗、驱虫、绝育、玩具 |
| **宠物狗** | 不分品种 | 幼犬(0-12月) → 成年(13月+) | 狗粮、疫苗、驱虫、绝育、玩具、遛狗用品 |

**核心属性**

```
养育对象
├── 基础属性
│   ├── id: String (唯一标识)
│   ├── name: String (用户自定义昵称)
│   ├── type: Enum (baby_boy/baby_girl/cat/dog)
│   ├── gender/breed: String (性别/品种)
│   ├── ageInMonths: Integer (月龄，从0开始)
│   ├── birthTime: DateTime (创建时间 = "出生"时间)
│   ├── status: Enum (healthy/hungry/sick/happy)
│   └── totalExpense: Double (累计花销)
│
├── 关联对象
│   ├── inventory: Inventory (物品栏，一对一绑定)
│   ├── activeEvents: List<LifeEvent> (当前事件列表)
│   └── eventTemplates: List<EventTemplate> (事件模板引用)
│
└── 行为方法
    ├── checkEvents(): List (检查应触发事件)
    ├── addExpense(amount): void (累计花销)
    └── consume Items(): void (日常物品消耗)
```

**多对象支持**

- 用户可同时创建多个养育对象（如宝宝+猫咪）
- 每个对象有独立的物品栏、事件列表、消费统计
- 通过左上角头像切换对象，右上角金额和物品栏同步切换
- 切换时加载对应对象的所有数据（从本地SQLite查询）

**扩展机制**

新增养育品类（v1.1+阶段）采用继承设计：

```
Creature (抽象基类)
├── Baby
│   ├── BabyBoy
│   └── BabyGirl
└── Pet (抽象)
    ├── PetCat
    └── PetDog
```

新增品类无需修改核心代码，只需：
1. 创建子类并实现 `checkEvents()` 方法
2. 配置事件模板和物品模板
3. 提供UI资源（形象图片、背景等）

### 2.2 事件系统（核心引擎）

事件系统是驱动APP的核心，自动根据养育对象的成长阶段和时间生成需要存钱的事件。

**事件四大类型**

| 事件类型 | 触发方式 | 实现方式 | 示例 |
|---------|---------|--------|------|
| **一次性事件** | 达到特定月龄时触发一次 | `trigger_month = target` | 新生儿首针疫苗、6月龄辅食添加、周岁体检 |
| **周期性事件** | 按固定时间间隔重复 | `interval_days = N` | 每月奶粉、每两周纸尿裤、每月猫粮 |
| **物品耗尽事件** | 物品栏中物品用完时 | 与物品消耗逻辑联动 | 奶粉用完了、猫砂用完了 |
| **状态事件** | 养育对象进入特定状态 | `status = sick/hungry` | 生病就医、情绪低落买玩具 |

**事件触发工作流**

```
[APP启动或定时tick]
  ↓
[事件引擎遍历所有事件模板]
  ↓
[逐个判断: shouldTrigger(now, creature)?]
  ↓
[满足条件 → 实例化LifeEvent]
  ↓
[加入待处理队列，发送系统通知]
  ↓
[显示事件弹窗]
  ↓
[用户操作: 确认存钱 / 稍后提醒]
  ↓
  ├─→ 确认：事件完成 → 金额累计 → 物品入栏
  └─→ 稍后：2小时后再提醒
```

**触发检查时机**

- APP启动时：完整检查
- APP前台运行时：每小时检查一次
- 物品消耗执行后：检查是否有物品耗尽
- 每日凌晨3点：定时日常检查

**事件配置表设计**

配置以JSON或SQL数据库存储，便于热更新：

```json
{
  "eventTemplates": [
    {
      "id": "E_BABY_FORMULA",
      "creatureType": "baby",
      "title": "该买奶粉了",
      "description": "宝宝每月需要2罐奶粉",
      "amount": 360,
      "type": "recurring",
      "triggerMonth": null,
      "intervalDays": 30,
      "relatedItemId": "ITEM_FORMULA_STAGE1",
      "icon": "icon_milk_powder"
    },
    {
      "id": "E_BABY_VACCINE_1",
      "creatureType": "baby",
      "title": "宝宝的第一针疫苗",
      "description": "乙肝疫苗，需要存备预防费用",
      "amount": 200,
      "type": "one_time",
      "triggerMonth": 0,
      "intervalDays": null,
      "relatedItemId": null,
      "icon": "icon_vaccine"
    }
  ]
}
```

**事件完成的后续操作**

1. ✅ 事件标记为已完成（is_completed = 1）
2. 💰 金额加入 creature.totalExpense
3. 📦 关联物品自动加入物品栏（如存在）
4. 🎬 显示成功动画（金币落入存钱罐）
5. 📊 消费统计页数据同步更新

### 2.3 物品栏系统

物品栏记录养育对象当前拥有的物资，模拟真实消耗。

**物品核心属性**

```
物品(Item)
├── id: String (物品实例ID)
├── name: String (如"婴儿奶粉3段")
├── category: Enum (food/hygiene/medical/toy)
├── quantity: Integer (当前数量，如3罐)
├── unitPrice: Double (单价，用于统计)
├── durationDays: Integer (单份可用天数，如15)
├── purchaseTime: DateTime (购买时间戳)
├── consumedDays: Integer (已消耗天数)
└── status: Enum (sufficient/low/exhausted)

计算方法:
  remainingDays = quantity × durationDays - consumedDays
  status = remainingDays > 7 ? 'sufficient' 
         : remainingDays > 0 ? 'low' 
         : 'exhausted'
```

**物品栏UI规格**

```
位置：屏幕左侧
宽度：屏幕宽度 × 1/3
高度：宽度数值 × 2（即屏幕宽度 × 2/3）
圆角：16dp
背景：半透明白色 (85% 透明度)
阴影：轻微

内部布局（竖向）:
┌─────────────────┐
│  物品栏 (5种)   │← 标题 40dp
├─────────────────┤
│  🍼 食品       │← 分类标签 11sp
│  奶粉 ×3       │← 物品条目 56dp
│  剩余 15 天    │   
│─────────────────│
│  🟡 奶粉 ×1    │← 预警状态(黄色)
│  剩余 5 天     │
│─────────────────│
│  🧻 卫生       │
│  纸尿裤 ×2     │
│  剩余 14 天    │
│─────────────────│
│ [滚动区]       │← 超出时可滚动
└─────────────────┘
```

**物品获取方式**

1. **事件自动增加**（主要）：用户确认事件后，关联物品自动加入
2. **手动添加**（辅助）：用户点击物品栏"+"按钮，从模板库选择手动添加

**物品消耗机制**

```
[每日定时执行] (如凌晨3点)
  ↓
[物品栏执行consumeAll(days=1)]
  ↓
[遍历所有物品，consumedDays++]
  ↓
[重新计算remainingDays和status]
  ↓
  ├─→ remainingDays ≥ 7: 绿色(sufficient)
  ├─→ 0 < remainingDays < 7: 橙色(low) + UI高亮
  └─→ remainingDays = 0: 红色(exhausted) + 触发补充事件 + 从栏删除
```

**状态预警**

- ✅ 充足状态(绿)：remainingDays ≥ 7，正常展示
- ⚠️ 预警状态(橙)：0 < remainingDays < 7，背景变橙色，字体变橙色
- ❌ 耗尽状态(红)：remainingDays = 0，自动触发补充事件，从物品栏删除

### 2.4 存钱记账流程

**核心流程**

```
[事件弹窗出现]
  ↓ 用户查看建议金额
[用户确认存钱]
  ↓
[系统记录事件为已完成]
  ↓
[金额累计到totalExpense]
  ↓
[关联物品加入物品栏]
  ↓
[显示成功动画]
  ↓
[APP提示: "请向[宝宝基金]存入¥360"]
  ↓
[用户在实际存钱工具中存入金额]
  ↓
[返回APP，完成一个存钱周期]
```

**金额建议算法**

```
建议金额 = 事件模板中的baseAmount × userCoefficientSetting

userCoefficientSetting 选项:
  - 节省模式: 0.8x (降低存钱压力)
  - 标准模式: 1.0x (真实养育成本)
  - 富养模式: 1.5x (优质生活)

用户可在[设置]中修改全局系数
每次事件前也可点击[调整金额]临时修改
```

**账户绑定指引**

用户在设置中可配置存钱账户名称（可选）：

```
用户输入范例:
- "支付宝小荷包-宝宝基金"
- "微信零钱通-宠物医疗"
- "建行定期存款-教育基金"

事件确认后弹窗显示:
"请向【宝宝基金】存入¥360"

作用：
  1. 强化用户的存钱动作
  2. 多账户用户清晰分类
  3. 增加情感连接
```

**未确认事件处理**

- 系统保留未确认事件，每天1次本地通知提醒
- 事件支持"稍后提醒"（2小时后再通知）
- 事件支持"忽略"（不计入消费，但记录为dismissed）
- 已忽略事件不再提醒，但保存在历史记录中

### 流程三：物品消耗与自动补充

```
[每日凌晨3点 or APP进入前台]
  ↓
[触发日常消耗逻辑: inventory.consumeAll(days=1)]
  ↓
[遍历物品栏中的所有物品]
  for item in inventory.items:
    item.consumedDays++
    remainingDays = item.quantity * item.durationDays - item.consumedDays
    ↓
    if remainingDays >= 7:
      item.status = 'sufficient'      ← 绿色
    elif remainingDays > 0:
      item.status = 'low'             ← 橙色预警
      (UI更新此物品的背景/文字颜色)
    else:  (remainingDays <= 0)
      item.status = 'exhausted'       ← 红色
      (UI显示红色并移除此物品条目)
      ↓
      [自动触发物品耗尽事件]
      event = new ItemDepletionEvent(item)
      event.title = "奶粉已用完，该补充了"
      event.amount = item.unitPrice * 2  (建议补充2个)
      event.relatedItem = item
      activeEvents.push(event)
      ↓
      [发送通知提醒]
  ↓
[物品栏UI实时更新]
  主页物品栏显示最新状态
  预警物品高亮显示
```

### 5.2 技术选型

| 层级 | 推荐方案 | 备选方案 | 选择理由 |
|------|---------|--------|--------|
| 跨端框架 | **Flutter 3.0+** | React Native | 动画和UI一致性，性能优秀 |
| 状态管理 | **Riverpod** | Provider, BLoC | 函数式，易测试，类型安全 |

### 5.4 核心类设计

**Creature 基类**

```dart
abstract class Creature {
  String id;
  String name;
  CreatureType type;
  int ageInMonths;
  DateTime birthTime;
  CreatureStatus status;
  Inventory inventory;
  List<LifeEvent> activeEvents;
  double totalExpense;

  // 月龄计算 (基于当前时间和出生时间)
  int calculateAgeInMonths() {
    final now = DateTime.now();
    final diff = now.difference(birthTime);
    return diff.inDays ~/ 30; // 简化为30天一个月
  }

  // 检查应触发的事件 (子类实现)
  List<LifeEvent> checkEvents();

  // 日常消耗 (物品栏自动消耗)
  void consumeItems() {
    inventory.consumeAll(days: 1);
  }

  // 累计花销
  void addExpense(double amount) {
    totalExpense += amount;
  }

  // 保存到数据库
  Future<void> save();
}
```

**Item 基类**

```dart
abstract class Item {
  String id;
  String name;
  ItemCategory category;
  int quantity;
  double unitPrice;
  int durationDays; // 单份可用天数
  int consumedDays;
  DateTime purchaseTime;

  // 计算剩余可使用天数
  int getRemainingDays() {
    return quantity * durationDays - consumedDays;
  }

  // 消耗逻辑
  void consume(int days) {
    consumedDays += days;
  }

  // 是否已耗尽
  bool isExpired() {
    return getRemainingDays() <= 0;
  }

  // 获取当前状态
  ItemStatus getStatus() {
    final remaining = getRemainingDays();
    if (remaining >= 7) return ItemStatus.sufficient;
    if (remaining > 0) return ItemStatus.low;
    return ItemStatus.exhausted;
  }
}
```

**Inventory 物品栏**

```dart
class Inventory {
  String creatureId;
  List<Item> items = [];

  // 添加物品
  void addItem(Item item) {
    items.add(item);
  }

  // 移除物品
  void removeItem(String itemId) {
    items.removeWhere((item) => item.id == itemId);
  }

  // 按分类获取物品
  List<Item> getItemsByCategory(ItemCategory category) {
    return items.where((item) => item.category == category).toList();
  }

  // 获取即将耗尽的物品 (用于预警)
  List<Item> getExpiringItems(int thresholdDays) {
    return items
        .where((item) => item.getRemainingDays() > 0 && item.getRemainingDays() <= thresholdDays)
        .toList();
  }

  // 日常消耗 (所有物品)
  void consumeAll({int days = 1}) {
    for (var item in items) {
      item.consume(days);
    }
    // 移除已耗尽的物品
    items.removeWhere((item) => item.isExpired());
  }

  // 分组获取 (用于UI显示)
  Map<ItemCategory, List<Item>> getGroupedItems() {
    final grouped = <ItemCategory, List<Item>>{};
    for (var item in items) {
      if (!grouped.containsKey(item.category)) {
        grouped[item.category] = [];
      }
      grouped[item.category]!.add(item);
    }
    return grouped;
  }
}
```

**LifeEvent 事件基类**

```dart
abstract class LifeEvent {
  String id;
  String title;
  String description;
  double amount;
  EventType type; // recurring, one_time, item_depletion
  DateTime triggerTime;
  bool isCompleted;
  String? relatedItemId;
  DateTime? completedTime;

  // 判断是否应触发 (子类实现)
  bool shouldTrigger(Creature creature);

  // 标记完成
  void complete() {
    isCompleted = true;
    completedTime = DateTime.now();
  }

  // 保存到数据库
  Future<void> save();
}

// 具体子类示例
class RecurringEvent extends LifeEvent {
  int intervalDays;
  DateTime lastTriggered;

  @override
  bool shouldTrigger(Creature creature) {
    final daysSinceLastTrigger = DateTime.now().difference(lastTriggered).inDays;
    return daysSinceLastTrigger >= intervalDays;
  }
}

class OneTimeEvent extends LifeEvent {
  int triggerMonth;

  @override
  bool shouldTrigger(Creature creature) {
    return creature.ageInMonths == triggerMonth;
  }
}
```

**EventEngine 事件引擎**

```dart
class EventEngine {
  Creature creature;
  List<EventTemplate> templates;

  EventEngine(this.creature, this.templates);

  // 核心方法：检查应触发的事件
  Future<List<LifeEvent>> checkEvents() async {
    final triggeredEvents = <LifeEvent>[];

    for (var template in templates) {
      final event = _createEventFromTemplate(template);
      if (event.shouldTrigger(creature)) {
        triggeredEvents.add(event);
      }
    }

    return triggeredEvents;
  }

  // 从模板创建事件实例
  LifeEvent _createEventFromTemplate(EventTemplate template) {
    switch (template.type) {
      case EventType.recurring:
        return RecurringEvent(
          id: uuid.v4(),
          title: template.title,
          amount: template.amount,
          intervalDays: template.intervalDays!,
          triggerTime: DateTime.now(),
        );
      case EventType.oneTime:
        return OneTimeEvent(
          id: uuid.v4(),
          title: template.title,
          amount: template.amount,
          triggerMonth: template.triggerMonth!,
          triggerTime: DateTime.now(),
        );
      // ...其他类型
    }
  }

  // 处理事件完成 (用户确认存钱)
  Future<void> completeEvent(LifeEvent event) async {
    event.complete();
    creature.addExpense(event.amount);

    // 如果事件关联物品，自动加入物品栏
    if (event.relatedItemId != null) {
      final itemTemplate = _getItemTemplate(event.relatedItemId!);
      final item = _createItemFromTemplate(itemTemplate);
      creature.inventory.addItem(item);
    }

    // 保存到数据库
    await event.save();
    await creature.save();
  }
}
```
