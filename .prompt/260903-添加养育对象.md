创建一个养育对象的父类用于模板，然后其他角色继承父类，这样方便管理和拓展更新，父类要有如下属性，名称、年龄（月天，自创建之日算起）、创建时间（时间戳）、性别、还有其他你觉着用得着的属性（最后列出来告诉我你还加了什么）
```plaintext
技术栈：Kotlin + Jetpack Compose（沿用上轮基线），minSdk 26。
职责划分：本模块为数据层/领域模型，与 UI 完全解耦，只含类定义与派生逻辑，不涉及界面。

■ 类层次设计（可扩展模板）
abstract class PetBase : PetInterface   // 养育对象抽象基类（模板），禁止直接实例化
    │
    ├── class Baby : PetBase()   // 婴儿：用 gender 区分男婴/女婴
    ├── class Cat  : PetBase()   // 猫猫
    └── class Dog  : PetBase()   // 狗狗
（选用 abstract class 而非 sealed class：便于后续在包外新增角色类型）

■ 父类 PetBase 属性
- id: String                      // UUID 唯一标识（每只角色唯一）
- name: String                    // 名称（用户命名后的名字）
- gender: Gender                  // 枚举：MALE / FEMALE / UNKNOWN（类型化，不用字符串）
- createdAt: Long                 // 创建时间戳，UTC 毫秒（System.currentTimeMillis() 落库）
- avatarEmoji: String?            // emoji 外观（👶/👧/🐱/🐶），无图片时兜底
- imageRes: Int?                  // 图片资源 id（如 R.drawable.baby_m1），优先于 emoji
- health: Int                     // 健康度 0–100，默认 100
- hunger: Int                     // 饱腹度 0–100，默认 100
- happiness: Int                  // 心情 0–100，默认 100
- lastInteractAt: Long?           // 上次互动时间戳，供离线衰减计算

■ 年龄：派生属性（不存储，只存 createdAt）
- 年龄 = 当前时间 − createdAt 动态计算，避免存储过期数据。
- getAgeInMonths(): Int          // 整月数（java.time.Period）
- getAgeDisplay(): String        // "X月Y天"；<1 天显示"刚刚"；≥12 月显示"X岁Y月"
- 计算路径：createdAt(Instant) → ZoneId.systemDefault() → LocalDate，与当前 LocalDate 做 Period.between()，
  用 calendar 差值而非 30 天/月近似，保证月天数差异准确。

■ 开放成员（子类差异点，模板扩展口）
- open fun getDefaultName(): String        // 默认命名：Baby→"男婴/女婴"，Cat→"猫猫"，Dog→"狗狗"
- open val defaultAvatar: String           // 各角色默认 emoji
- open fun getAvatar(): Any?               // 返回 imageRes（有图）或 emoji（无图），供 UI 层读取
- 后续新增角色只需继承 PetBase 并覆写差异成员，父类逻辑全部复用。

■ 子类
- Baby(gender: Gender)：gender 决定男婴/女婴；默认名、默认 emoji 随 gender 分支。
- Cat / Dog：默认名"猫猫/狗狗"；预留 breed（品种）字段以支持未来扩展。
```
